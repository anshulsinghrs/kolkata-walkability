      About UrbanPulse

      UrbanPulse is an open-source platform for urban walkability and mobility intelligence. Search any city, layer OpenStreetMap data, recompute walkability scores under custom indicator weights, and overlay your own observations.

      The walkability score model combines built-environment indicators — sidewalk quality, greenery, lighting, crowdedness, crossing safety — weighted by a stated-preference coefficient set you can edit in the Weights tab.

      How to use

      1. 1
        Pick a city Search any place from the top bar — the map fits to its OSM bounds.
      2. 2
        Choose a basemap OSM, Positron, Dark, Satellite, or Topo — in the Map tab.
      3. 3
        Upload your data Drop a CSV or GeoJSON in the Data tab — columns auto-detect.
      4. 4
        Style the layer Points, heatmap, or clusters in Layers; tune the color scale.
      5. 5
        Tune the score Adjust indicator coefficients in Weights to recompute live.
      6. 6
        Export Download the current view as GeoJSON, CSV, or PNG.

      CSV format

      Only latitude and longitude are required. Common header variants are detected automatically.

      example.csv UTF-8 
      latitude,longitude,weightage,category,sidewalk,greenery,lighting,crowdedness,crossing_safety,notes,timestamp,image_url

22.5810,88.3501,38,hazard,0.3,0.2,0.4,0.9,0.2,Flooded sidewalk,,
      Column Accepted aliases
      • latitude req lat · y
      • longitude req lng · lon · long · x
      • weightage weight · score · pws · walkability · value
      • category class · type · tag
      • sidewalk —
      • greenery green · vegetation
      • lighting streetlight · light
      • crowdedness crowd · density
      • crossing_safety crossing · safety
      • notes note · comment · remark · description
      • timestamp time · date · datetime
      • image_url image · photo · img · picture
      • hazard_type hazard · incident

      Values 0–1 are auto-rescaled to 0–100. Missing weights default to 50. GeoJSON FeatureCollection files work too — point geometries are read and feature properties match the same column names.
